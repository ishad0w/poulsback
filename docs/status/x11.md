# X11 desktop status

WIP. Xorg runs the poulsback DDX and accelerated GL clients on the Dell.
The complete everyday-desktop and one-hour acceptance criteria remain open.

## Working and checked

- **DDX:** Xorg 21.1.7 uses KMS, EXA on the 2D core, DRI3 1.2 and Present.
  Fills and copies run on the GPU where measured faster; small operations
  stay on the CPU. Unaligned destinations use a head/body split
  ([2D status](2d.md), [hardware facts](../hardware.md#memory-and-address-domains)).
- **Presentation:** windowed GL frames use 2D copies into the front without
  a CPU frame copy or blocking CPU wait. Fullscreen SCANOUT windows flip;
  covering one switches it to copies, and uncovering permits flips again.
  Mesa's `pipe->blit` preserves reallocated back buffers. Frame comparisons
  and an xterm over running GL check visible contents
  ([frame path](../graphics.md#frame-path)).
- **Measured subset:** the x11perf wide subset reaches the better of EMGD
  and PSB except putimage500, which is limited by the X stack. The smoke
  rendercheck subset passes 18/18. Wider Render checks expose an EXA triangles
  failure for unbounded operators, and several Render text/trapezoid rates
  remain below the best legacy reference. The full selection has not passed.
- **Device loss:** the DDX disables acceleration, repaints and continues
  on the CPU. GL clients receive errors, and GPU-reachable resources remain
  held until reboot.
  VT switching during the loss and the full CPU-wait trace remain unverified
  ([loss policy](../kernel/execution.md#the-loss)).

## In progress

- Render composition beyond fills and copies stays on the CPU. The planned
  route is EXA Composite on the 3D core through a library shared with Mesa;
  glamor is an alternative pending measurements after render-target support.
- Complete Render operators, masks, formats, transforms, glyphs, gradients and
  the triangles fix, then full x11perf/rendercheck selections.
- Qualify panel output control, DPMS, VT switching, cursor, gamma, colour maps,
  textured Xv, Composite under xfwm4 and server regeneration. VGA is excluded
  from M1 for now ([accepted exclusions](../../spec/exclusions.json)).
- Complete application lifetime acceptance, sharing, concurrent clients and
  the everyday desktop soak. Existing application runs do not close every
